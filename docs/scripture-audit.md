- 首頁的詩篇 119:11 另外按來源第 11 節核對。
- 逐字比較文字、字形、標點與括注；僅移除來源頁面的逐字排版空白、節號及註腳連結，不對中文字做正規化或同義替換。
- 跨節經文按節號直接串接，不增加省略號或補寫引號。個別節若在來源中包含跨節引號，保留來源原貌。
- 22 張聖經卡的文字與來源有差異，另有 5 張卡的出處名稱或空白格式統一。差異包含不同電子版的用字、字形、括注及標點，不能全部視為原稿錯字。

## 驗證與限制

來源快照與逐卡差異分別保存在 `verification/cuv-passages.json` 與 `verification/scripture-audit.json`，含逐節文字、來源網址、擷取時間及 SHA-256。

執行 `npm run verify:scriptures` 會確認所有聖經卡與固定來源逐字相等，並檢查出處完整性、卡片 ID、課程補充分類、首頁經文與純中文介面。正式建置前自動執行，任何文字或標點不符即失敗。

「逐字一致」限於以上明確指定的電子版，不能推論與所有紙本／新標點／字形版本完全相同。重新下載來源快照後，必須重新審查差異，不能直接覆寫網站內容。

現有中文朗讀保留原始音檔網址；本次未逐字核對錄音，無法宣稱音檔與修正後字句完全一致。
